BoardGames — приложение для поиска настольных игр, реализованное на C# (.NET 8.0. с использованием WPF. Решение состоит из двух проектов: BoardGames.WPF содержит графический интерфейс, Model содержит библиотеку бизнес-логики.

Чтобы запустить приложение, нужно открыть файл BoardGamesSolution.sln в Visual Studio 2022, убедиться что стартовый проект BoardGames.WPF и нажать F5. При первом запуске автоматически создаётся файл data/games.json с 15 предустановленными играми. При повторных запусках данные загружаются из этого файла.

Проект BoardGames.WPF содержит файлы App.xaml и App.xaml.cs — точка входа приложения, MainWindow.xaml и MainWindow.xaml.cs — главное окно, GameDetailWindow.xaml и GameDetailWindow.xaml.cs — окно с подробными данными об игре, CatalogWindow.xaml и CatalogWindow.xaml.cs — окно управления каталогом, AddGameWindow.xaml и AddGameWindow.xaml.cs — форма добавления новой игры.

Проект Model содержит папку Core с файлами BoardGame.cs — абстрактный базовый класс, CardGame.cs, EuroGame.cs, PartyGame.cs — наследники BoardGame, IGameCatalog.cs — интерфейс каталога, IAnalizer.cs — интерфейс аналитики, GameCatalog.cs и GameCatalog.Analizer.cs — две части partial-класса каталога, GameFactory.cs — создание стартовых игр. Папка Data содержит GameDto.cs — вспомогательный класс для сериализации и GameSerializer.cs — сохранение и загрузка из файла.

Главное окно открывается при запуске. В верхней части находится выпадающий список со всеми играми каталога, отсортированными по алфавиту. Рядом расположена кнопка Показать данные, которая неактивна пока не выбрана игра. После выбора игры кнопка становится активной и открывает окно с подробной информацией. Ниже расположена кнопка Открыть каталог. В нижней части отображается блок аналитики с общим количеством игр, средним минимальным и максимальным количеством игроков, средним диапазоном и средним минимальным возрастом. Блок обновляется автоматически после закрытия окна каталога.

Окно деталей открывается по кнопке Показать данные. Пока оно открыто, главное окно недоступно. В левой части отображается обложка игры, если файл изображения не найден это место остаётся пустым. В правой части показаны название, тип игры, диапазон числа игроков, минимальный возраст и уникальное поле в зависимости от типа. Для карточных игр это размер колоды, для евро-игр сложность правил со значениями Low, Medium или High, для пати-игр признак шумности. Ниже выводится описание игры с прокруткой при длинном тексте.

Окно каталога открывается по кнопке Открыть каталог. Пока оно открыто, главное окно недоступно. Окно содержит таблицу со столбцами название, тип, минимальное и максимальное количество игроков, минимальный возраст и описание. Чтобы выбрать игру для удаления нужно кликнуть по строке таблицы, затем нажать кнопку Удалить выбранную и подтвердить действие в появившемся диалоге. Кнопка Добавить игру открывает форму добавления. После закрытия окна каталога главное окно обновляет список и пересчитывает аналитику.

Окно добавления открывается по кнопке Добавить игру. Форма содержит поле названия, выпадающий список типа игры, поля минимального и максимального количества игроков, поле минимального возраста, уникальное поле которое меняется в зависимости от типа и поле описания. При выборе типа CardGame появляется поле размера колоды. При выборе EuroGame появляется список сложности. При выборе PartyGame появляется чекбокс шумная игра. Кнопка Добавить проверяет все поля и при ошибке показывает диалог с описанием проблемы. При успешной проверке игра добавляется в каталог и сохраняется в файл. Кнопка Отмена закрывает окно без изменений.

Все данные хранятся в файле data/games.json рядом с исполняемым файлом. Файл создаётся при первом запуске и перезаписывается полностью при каждом добавлении или удалении игры.

Изображения обложек хранятся в папке images рядом с исполняемым файлом в формате jpg или png. Путь задаётся в поле ImagePath в виде images/название.jpg. Если файл не найден, поле обложки остаётся пустым и приложение продолжает работу без ошибок.
